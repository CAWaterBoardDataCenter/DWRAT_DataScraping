Workflow Steps
(Better documentation will come eventually)


0. Setup the Master Control File (required for entire repo)


1. Decide on a workflow version to use


2. Setup the RR Workflow Control File


3. Decide how you would like to run the procedure:

	Option 1: Specify data scraping dates in "CTR_001_Set_Start_and_End_Dates.R" and use a workflow version's master script
	
	Option 2: Use the workflow's "Run Process Today" script
	
	Option 3: Use a batch file (developed by "HLP_006_Generate_RR_Workflow_Bat.R" and stored in the "Workflow_Bin" folder)
	
		(e.g., by clicking on it or using Windows Task Scheduler)
